## 誠實界線

Prompt 規則不是系統強制限流；本地 runner 不是安全沙箱；子任務會話不等於操作系統隔離；
客戶端退出存活不代表 Gateway/容器重啟存活；一次測試成功不代表所有任務穩定。
**跨 CLI 進程接手 ≠ 已驗證聊天 `/new` 或容器重啟。**
